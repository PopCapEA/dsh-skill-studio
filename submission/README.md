# Market submission

This directory holds the prepared `awesome-dsh-plugin` entry for
`PopCapEA/dsh-skill-studio`.

1. Copy `PopCapEA__dsh-skill-studio.yml` to
   `data/plugins/PopCapEA__dsh-skill-studio.yml` in a clone of
   `awesome-dsh-plugin/awesome-dsh-plugin`.
2. Open one PR with only that file.

The package must already be public (npm or a public GitHub repository) before
the list CI can verify `dsh.bundle`. See `../PUBLISHING.md`.
